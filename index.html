An interactive guide to theNEST360 Implementation Model

NEST360's implementation model explains how evidence-based small and sick newborn care (SSNC) actually took hold in hospitals — from the barriers on the ground, through the strategies used to address them, to a measurable drop in newborn mortality.

This tool unpacks it in layers, so you can explore at whichever depth is useful to you:

  • Overview — the five-stage flow at a glance: Implementation Factors → Intervention → Strategies → Mechanisms → Outcomes → Impact.
  • Details — a general description of each stage, with NEST360's own specific coding (barriers, facilitators, strategies used) available to reveal underneath, one stage at a time.
